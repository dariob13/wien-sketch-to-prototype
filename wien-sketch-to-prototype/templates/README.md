# Vorlagen

## Doop

Canvas: <https://doop.design/c/B-iDTpuPIM>

- Seite **Skizze**: Beispielskizze „Bäder in Wien“ + „Hallenbäder“ (verlinkt), „Vorlage - leer“ und der „Spickzettel“.
- Seite **Prototyp**: das Ergebnis von `/wien-revamp` auf genau diese Skizze, zum Vergleichen.

Zum Arbeiten: Frame „Vorlage - leer“ duplizieren, umbenennen (= Seitenname) und Kästen anlegen. Der Quelltext der Skizzen-Frames liegt in `doop/` (`_style.css` ist der gemeinsame Wireframe-Stil). Damit lässt sich der Canvas jederzeit neu aufbauen.

## Figma

Datei: <https://www.figma.com/design/BpjyDcUpLZ1Mtg0ScmcbSc>

- Frame **Vorlage – leer**: Notiz, `[Bühne mit Bild]`, `[Abschnitt]`.
- Frames **Baden** und **Schwimmkurse**: grobe Skizze von wien.gv.at/freizeit/baden. Sie zeigen deutsche und englische Tags, geerbte Tags, einen Gruppen-Tag, einen Tippfehler, Kästen ohne Tag, eine Prototyp-Verbindung und einen gezeichneten Pfeil.

Zum Arbeiten: In Figma *Duplicate to your drafts* wählen und dann den Link zur Seite (mit `node-id`) an `/wien-revamp` geben.

Ergebnis Pilot 2: <https://doop.design/c/vUy47I8paK> (Referenz = Live-Seite, Skizze, Prototyp).
